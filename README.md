# ZS-BOARD

Windows 桌面整理工具，提供启动台、分组、Dock 和桌面图标收纳。

[下载最新安装包](https://github.com/zhangs0210/ZS-BOARD/releases/latest/download/ZS-BOARD-Setup.exe) · [查看更新日志](https://github.com/zhangs0210/ZS-BOARD/releases/latest)

## 安装与更新

- 下载安装包并运行，可自行选择安装位置。
- 升级沿用已有配置，保留分组、排序和 Dock 固定项。
- 从 1.3.49 开始，支持后台检查更新。发现新版时，启动台显示“有更新”；点击并确认后才下载和安装。
- 在“设置 → 关于与更新”中，可关闭自动检查、手动检查或查看离线更新日志。
- 更早版本首次使用更新功能，需要先手动安装 1.3.49 或之后的版本。

在线更新需要能够访问 GitHub。此仓库分发安装包与更新日志。
